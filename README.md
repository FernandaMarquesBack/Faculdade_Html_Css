 # 🛡️ Página Web Simples — Ponto Seguro

## 📌 Sobre o projeto

Este projeto foi desenvolvido para fins **didáticos e acadêmicos**, como parte da disciplina de **Web Standards** do curso de **Produção Visual — Senac EAD**.

A proposta inicial da atividade era desenvolver uma **página web simples utilizando HTML e CSS**, proporcionando um primeiro contato prático com a estruturação de páginas, organização de conteúdos e aplicação de estilos.

O projeto consiste na criação de uma página para apresentar os serviços de um **profissional autônomo especializado em segurança da informação e hacking ético**, reunindo informações sobre sua atuação, serviços oferecidos e formas de contato.

## 🎯 Objetivos

Durante o desenvolvimento da página, foram trabalhados conceitos fundamentais de desenvolvimento web, como:

* Estruturação de conteúdo utilizando **HTML5**;
* Criação de títulos, parágrafos e listas;
* Organização de informações em uma página web;
* Utilização de **CSS3** para estilização;
* Aplicação de cores, tamanhos de fonte, alinhamentos e espaçamentos;
* Criação de menus e links de navegação;
* Organização de informações sobre serviços e contato;
* Desenvolvimento de uma identidade visual relacionada ao tema de **cibersegurança**.

## 💻 Sobre a página

A página foi desenvolvida com o conceito de um profissional fictício chamado **Ponto Seguro — Hacker Ético**.

A proposta visual foi inspirada no universo da **segurança digital**, utilizando uma estética predominantemente escura, elementos em verde e referências visuais à tecnologia e ao universo hacker.

A página apresenta:

* **Nome e identidade visual** do profissional;
* Uma breve apresentação sobre sua atuação;
* Os principais **serviços oferecidos**;
* Teste de invasão (*Pentest*);
* Análise de vulnerabilidades;
* Consultoria em segurança digital;
* Informações de **telefone, e-mail e site**;
* Menu de navegação entre as diferentes seções;
* Elementos visuais e animações para tornar a experiência mais dinâmica.

## 🚀 Desenvolvimento e diferenciais

Como o enunciado permitia liberdade na escolha do **tema e da estrutura da página**, decidi ir um pouco além dos requisitos propostos e explorar outras possibilidades durante o desenvolvimento.

Além do **HTML5 e CSS3**, utilizei **JavaScript** para adicionar maior dinamismo e personalidade à interface. A intenção foi fazer com que a página não fosse apenas uma aplicação dos conceitos básicos solicitados, mas também representasse uma identidade visual própria e mais próxima de um projeto real.

Um dos principais elementos desenvolvidos foi o **efeito Matrix**, utilizando **JavaScript** em conjunto com o elemento **`<canvas>` do HTML**. O código gera caracteres de forma dinâmica e cria uma animação contínua inspirada no conhecido efeito visual da franquia *Matrix*.

Para tornar a animação mais personalizada e relacionada ao conceito do projeto, foram utilizados diferentes conjuntos de caracteres, incluindo números, letras e caracteres de diferentes sistemas de escrita.

Dessa forma, o JavaScript passou a complementar o HTML e o CSS, permitindo criar uma experiência visual mais dinâmica e demonstrando, na prática, como essas três tecnologias podem trabalhar em conjunto.

### ✨ O que foi além do solicitado

Embora a atividade tivesse como foco principal **HTML e CSS**, foram adicionados alguns recursos extras:

* Utilização de **JavaScript**;
* Criação de uma animação utilizando **`<canvas>`**;
* Desenvolvimento de um efeito visual inspirado no **Matrix**;
* Criação de uma identidade visual própria;
* Utilização de **Google Fonts** para personalização da tipografia;
* Criação de efeitos de interação nos links e botão;
* Exploração de diferentes elementos visuais relacionados à **cibersegurança**;
* Maior preocupação com a experiência visual e a personalidade da página.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estruturação e organização do conteúdo;
* **CSS3** — estilização, layout, cores, fontes e efeitos visuais;
* **JavaScript** — animações e elementos dinâmicos;
* **HTML Canvas** — criação do efeito de caracteres em movimento;
* **Google Fonts** — personalização das fontes utilizadas no projeto.

## 📚 Finalidade acadêmica

Este projeto representa uma das primeiras experiências práticas com **desenvolvimento web**, tendo como objetivo aplicar os conceitos apresentados na disciplina de **Web Standards**.

A atividade serviu como ponto de partida para compreender a relação entre **HTML, CSS e JavaScript**: enquanto o HTML é responsável pela estrutura e organização do conteúdo, o CSS define sua apresentação visual e o JavaScript permite adicionar comportamentos, interações e elementos dinâmicos.

A liberdade oferecida no enunciado também possibilitou explorar recursos além dos requisitos básicos, transformando uma atividade de introdução ao desenvolvimento web em uma oportunidade para experimentar, criar e desenvolver uma identidade própria para o projeto.

> **Projeto desenvolvido para fins acadêmicos e didáticos.**
